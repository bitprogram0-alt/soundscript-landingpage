FAQ

Frequently asked questions

Still have questions? Email bitprogram0@gmail.com.

Is this a one-time purchase or a subscription?
One-time purchase. No subscription, no recurring fees. You get the app, all future bug fixes, and free updates — forever. Cloud engine usage is billed separately by ElevenLabs and Google, on your own accounts. We never touch your API keys.
Do I need an ElevenLabs subscription?
Not necessarily. ElevenLabs is optional — you can use the fully offline Anhad engine with no accounts at all. If you do want ElevenLabs voices, you bring your own API key. ElevenLabs has a free tier that's a good starting point.
Does it really work offline?
Yes. After downloading the Anhad (TTS) and Nuqta (LLM) models once, everything runs on your machine. No internet connection is required to generate audio or write scripts with local engines.
What are the system requirements?
OS: Windows 10/11 or Linux (Ubuntu, Fedora, Kali, most modern distros).
RAM: 4 GB minimum. 8 GB recommended for local models.
Disk: ~500 MB for the app, plus ~340 MB for Anhad and up to ~2.5 GB per Nuqta model.
Internet: Only needed for cloud engines and initial model downloads.
How many devices can I install it on?
Each license activates on up to three devices that you own or control. That covers the common "desktop + laptop" case with one spare. Need more? Contact support.
Can I get a refund?
Refunds are handled through Gumroad's standard policy. If you run into a problem that we can't fix, reach out first — bitprogram0@gmail.com — and we'll work it out.
Is macOS supported?
Not yet. macOS support is on the roadmap but there's no firm timeline. If macOS is a hard requirement for you, hold off for now.
Will it work on my GPU-less machine?
Yes. All local models (Anhad and Nuqta) run on CPU. No GPU required. A faster CPU means faster generation, but any modern x86-64 processor will work.
